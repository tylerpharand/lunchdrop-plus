# Installation

Builds are on the [latest release](https://github.com/tylerpharand/lunchdrop-plus/releases/latest).

## Chrome (Desktop)

Download `lunchdrop-plus-<version>-chrome.zip` and unzip it. Open `chrome://extensions`, turn on Developer mode, and load the unzipped folder.

The zip does not auto-update.

## Firefox (Desktop)

Download `lunchdrop-plus-<version>-firefox.xpi`. Open Add-ons and themes, then choose Install Add-on From File from the settings menu.

That file is attached after addons.mozilla.org signs the release. Desktop Firefox and Firefox for Android use the same package.

## Firefox (Mobile)

Download `lunchdrop-plus-<version>-firefox.xpi`. Open Settings, then About Firefox, and tap the logo five times. Then choose Install Extension from File.
